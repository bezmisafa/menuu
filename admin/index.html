YAYIN BAĞLANTISI

GitHub’a bağlan

Panel, menünüzü GitHub deponuza kaydeder. GitHub Pages yayını güncellediğinde değişiklikler sitenize yansır.

Anahtar yalnızca bu sekmenin belleğinde tutulur. Sekmeyi kapattığınızda silinir. Anahtarınızı sohbetten paylaşmayın.

Erişim anahtarını nasıl alırım?
  1. GitHub’da fine-grained token oluşturun.
  2. Repository access bölümünde yalnızca menuu deposunu seçin.
  3. Repository permissions → Contents: Read and write iznini verin ve bir son kullanma tarihi belirleyin.
  4. Oluşan anahtarı buraya yapıştırın. Dal ve klasör, deponuzdaki Settings → Pages ayarıyla aynı olmalıdır.
